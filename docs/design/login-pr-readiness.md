# main 기준 회원가입·로그인 전용 범위

- 시작점: origin/main 5ed8191.
- 브랜치: codex/login-only.
- 회원가입 백엔드: 02caccc. 회원가입 프런트 필수 파일: 3d7beed.
- 로그인·세션·비밀번호 변경·비밀번호 찾기: 3ce2f33에서 선택 복사.
- developer를 병합하지 않았고 예약·캘린더·관리자·Slack 구현이나 임시 데이터를 추가하지 않았다.
- main에 이미 있던 DB 테이블과 공통 뼈대는 유지한다. 원래 main 파일까지 없앤다는 의미는 아니다.

회원가입 서비스·모델·DTO·API·메일러·테스트는 가입 원본과 같으며, 가입 프런트도 담당자 원본이다. 차단 이메일 재가입·비밀번호 조건·승인 정책은 변경하지 않는다. 로그인과 찾기는 재가입한 현재 계정을 선택하고 과거 차단 계정을 변경하지 않는다.

DB 이력은 0001 → 회원가입 0002 → login_0003이다. 다른 팀의 숫자 0003과 식별자가 충돌하지 않도록 로그인 revision을 별도로 명명했다. 향후 캘린더 등의 브랜치를 함께 병합하면 Alembic의 여러 head를 잇는 merge revision을 통합 담당자가 추가해야 한다. 현재 main 기준 브랜치에는 단일 head만 존재한다.

기존 실행 중인 폴더·브랜치·로컬 개발 DB·서버는 변경하지 않았다. 이미 다른 이력이 적용된 DB를 이 브랜치에 자동 연결하거나 stamp하지 않는다. 검증은 새 별도 _test DB에서 수행한다.

PR에는 main 기준의 회원가입 의존 코드와 로그인 담당 변경만 표시되어야 한다. 이후 대상 브랜치가 갱신되면 충돌·DB 이력은 다시 확인한다.
